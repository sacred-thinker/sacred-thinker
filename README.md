📌 Принимал участие в проекте "Каритас", в ходе которого разрабатывалось веб-приложение, позволяющее специалистам загружать PDF-файлы с результатами диагностики детей, автоматически анализировать данные и визуализировать динамику развития. Пользователь получает готовый отчёт в виде графиков, таблиц и может скачать его в PDF или CSV.
Основной функционал:

Загрузка PDF-файлов (одного или нескольких) Отправка файлов на сервер для анализа. Отображение результатов в таблицах и графиках - текстовые выводы ("Показатель X увеличился на Y%") - экспорт отчётов в PDF и CSV, адаптивный дизайн по макетам, простая и интуитивная работа.
